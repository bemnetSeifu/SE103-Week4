Problem:
Count how many numbers in a list are greater than 10.

Input:
a list of numbers

Output:
the count, or an error if the list is empty

Pseudocode:
START
1. IF the list is empty THEN
      Output "Error: list is empty"
      STOP
   ELSE
      Set count to 0.
2. FOR each number in the list:
      IF the number is greater than 10 THEN
         Add 1 to count.
      ELSE
         Do nothing.
3. Output count.
END
