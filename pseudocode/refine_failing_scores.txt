Problem:
Find which scores failed.

Input:
a list of student scores

Output:
the failing scores, or a message if no one failed

Failing rule:
score < 50

Pseudocode:
START
1. Create an empty list called failing_scores.
2. FOR each score in the list:
      IF score < 50 THEN
         Add the score to failing_scores.
3. IF failing_scores is empty THEN
      Output "No one failed."
   ELSE
      Output the failing_scores list.
END
