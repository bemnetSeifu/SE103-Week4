What a pull request asks teammates to do:
A pull request asks teammates to review changes before they are merged into the main branch. It gives reviewers a chance to check the work, leave feedback, and confirm that the changes are ready to be merged.

Why branches and pull requests are used together:
Branches allow developers to work on changes separately from the main branch. Pull requests then provide a place to review those changes before they are merged into main.
